RISC-V Processor Optimization

Digital Design Project · February–May 2025 · Simulation

I verified and debugged a five-stage RISC-V processor in simulation, then optimized its execution of an MNIST digit-classification workload.

Workload and baselineVerification and debuggingWhat I contributed

Workload and baseline

The starting point was a functional five-stage pipeline using non-custom instructions. The workload classified images of handwritten digits using an existing model: this was inference, rather than training the model.

Custom instructions and cache optimizations reduced runtime by 80% relative to that pre-optimization pipeline for the MNIST workload. This is a workload-specific simulation result, not a claim of an 80% improvement across arbitrary programs.

Verification and debugging

I debugged the processor’s combinational blocks, including the ALU and multiplexers, as well as pipeline behavior to establish functional operation. The project combined block-level logic debugging with running the application workload.

The work was performed in simulation. It did not include fabricated-silicon bring-up, scan testing, or ATE.

What I contributed

  • Verified and debugged a functional pipelined processor.
  • Applied custom-instruction and cache optimizations to the digit-classification workload.
  • Compared runtime against the functional pipeline before those optimizations.
